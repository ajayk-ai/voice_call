PO Agent: User Guide

For SCM, business users and administrators · Updated 20 Oct 2026

PO Agent follows up overdue purchase-order lines from the "CE - Pending PO" Google Sheet for the SCM team. Each day it checks which lines are overdue and escalates them step by step: by WhatsApp, an AI voice call, and finally a Google Meet with management.

Overview

PageAddressWho uses it
Business dashboard/dashboardSCM and business users: see overdue lines, choose vendors, edit vendor numbers
Admin page/adminAdministrators: runs, schedule, settings, per-vendor trace, test environment
Voice agent/Anyone with the app code: ring a number with the agent, or talk to it in the browser

How escalation works

A line moves up one scenario for each daily check in a row that finds it overdue (OD Days > 0).

Overdue checks in a rowScenarioWho is contactedAlso
1Scenario 1Vendor planner and coordinator, by WhatsApp
2Scenario 2Vendor management, by WhatsApp
3Scenario 3Buyer, by WhatsAppThe voice agent calls the vendor's Scenario 3 number
4 or moreMeetingBuyer and SCM HODA Google Meet invite is sent
  • A check where the line is not overdue breaks the streak. If it becomes overdue again, it starts at Scenario 1.
  • A day with no check (server off, holiday) neither counts nor breaks the streak.
  • Scenarios are never skipped, and each vendor gets at most one message per scenario per day.

Getting started

All you need is the server's web address and an access code from your administrator.

You want toAsk forThen open
See overdue lines and manage vendorsThe dashboard code (DASHBOARD_PASSWORD)https://<server>/dashboard
Run and configure follow-upsThe admin code (ADMIN_PASSWORD)https://<server>/admin
Place a test call with the voice agentThe app code (APP_PASSWORD)https://<server>/

The admin code also opens the dashboard. On the server PC itself, if no codes are set, the pages open without one.

Your first look at the dashboard

  1. Open /dashboard and enter your code.
  2. Pick a tab at the top: All overdue, Scenario 1, Scenario 2, Scenario 3 or Meeting. Each shows its count.
  3. Click any line to see its details: pending quantity, due date, days late, and which messages went out.
  4. Add ?env=test to the address to look at test data instead of production.

Your first test call

  1. Open / and choose the Normal call tab.
  2. Enter the phone number with country code, for example +919876543210, and the app code.
  3. Press call. The agent rings from the company FreJun number and speaks with a sample PO script.
  4. To try the agent without a phone, use the Voice agent tab and talk through your browser. Use headphones.

Using the app

Dashboard: watch overdue lines

The dashboard refreshes every 2 minutes. Each line shows pending quantity, due date, days late, its overdue streak over the last 7 checks, and the status of each scenario.

StatusMeaning
Sent + dateThe message for that scenario went out on that date
Due nowIt will go out on the next run
ConfirmedThe streak qualifies, but it waits for the previous scenario to be sent
On holdThe vendor is not selected for follow-up, or pilot mode holds it
Not yet + dateThe date the next check would confirm it
  • Search by PO, vendor or buyer, and filter by vendor, buyer or days late.
  • Sort any column, and group by PO or show all lines.
  • Export CSV downloads exactly what you have filtered.

Dashboard: choose which vendors are followed up

The Vendors to follow up panel sits at the bottom of the dashboard.

  1. Choose Selected vendors only (start with 5 to 10) or All vendors. Switching production to all vendors asks you to type ALL.
  2. Tick Follow up next to each vendor you want. Search by name, code or number.
  3. Press Save selection. Unticked vendors show On hold in the overdue list.

Dashboard: edit vendor phone numbers

Each vendor has a Scenario 1, 2 and 3 number, stored in the Phone_Master tab of the Google Sheet.

  • Press Edit next to a vendor (or in a line's details), or Add vendor for a new one.
  • Leave a number blank to use Master's numbers. A blank Scenario 3 uses Scenario 2's number.
  • Separate several numbers with commas.

For many vendors at once:

  1. Press Download CSV. It lists every vendor's code, name, Follow up (Yes/No) and Scenario 1/2/3 numbers.
  2. Edit it in Excel.
  3. Press Bulk upload and choose the file, or paste rows from Excel.
  4. Review the preview and press Apply. If any row is wrong, nothing is saved.

In the upload, missing columns and blank Follow up cells stay as they were. An empty Scenario cell clears that number.

Admin: run follow-ups

Pick Production or Test at the top, then use the tabs.

TabWhat you do there
OverviewCheck health, run now, see automatic run status and run history
Vendor traceFollow one vendor through Scenario 1, 2, 3 and the meeting, with every message and number used
Test a vendorRun a full escalation on one vendor in the Test environment
SettingsSet the schedule, check period, pilot mode and numbers
Data & logsSync the sheet, copy production into test, read the tracker and logs

Under Run now there are three buttons:

ButtonWhat happens
PreviewShows what would be sent. Nothing is sent or recorded
Dry runRecords the check and logs DRY_RUN rows, but sends no WhatsApp
Live runSends real messages. In production you must type LIVE to confirm

Click any run in Run history to see every message it produced.

Admin: test a vendor end to end

  1. Switch to the Test environment and open Test a vendor.
  2. Pick a vendor, enter your WhatsApp number and a short check period, for example 1 minute.
  3. Optionally enter a Scenario 3 call number. With Send real WhatsApp, the voice agent really rings it at Scenario 3. Leave it blank to ring your WhatsApp number.
  4. Press Start test. Scenario 1 goes out at once; Scenario 2, 3 and the meeting follow one period apart.
  5. Every message starts with "PILOT TEST – real recipient would be: …", so you can see who it would have reached.
  6. Use Run next step now to skip ahead, Stop automatic runs to pause, or Start over.

To hear the agent read a vendor's real overdue lines, use Call now in the same tab.

Voice agent page

  • Normal call rings any number from the company FreJun number.
  • Voice agent lets you talk to the agent in your browser, with no phone needed.
  • The agent speaks English, Hindi and Tamil. It answers in the language the other person uses.
  • During a Scenario 3 call, the agent confirms who it is speaking with, goes through each overdue PO line, and asks for dispatch status, dates and the reason for delay. It then reads back a summary.

Settings you can change

All of these live in Admin → Settings and are saved separately for Production and Test. Press Save settings when done.

SettingWhat it controls
Run automaticallyTurns the daily run on or off. Off by default
ModeDry run (no WhatsApp) or Live. Live asks you to type LIVE
ScheduleOnce a day at a time in IST (default 08:30), or every N minutes
Check periodHow long one overdue check lasts. Production: 1 day. Test: a few minutes
Pilot modeOnly selected vendors are processed, and every message goes to the pilot mobile
Pilot mobileThe number that receives all messages in pilot mode
Pilot call numberThe number the Scenario 3 voice agent call rings in pilot mode. Blank = pilot mobile
Selected vendor codesVendors followed up when scope is "selected". Also set from the dashboard
SCM HOD mobileWho joins the buyer at the meeting stage
PO lines per messageMaximum lines in one WhatsApp message (default 15)
Pull the latest Google Sheet before each runRefreshes production data just before the run

Recommended go-live order: keep pilot mode on and automatic runs on Dry for a few days, compare the dashboard with what you expect, then switch to Live.

Troubleshooting and FAQ

ProblemWhat to do
"Wrong access code"Check the code with your administrator. Dashboard, admin and call pages each have their own
"Set ADMIN_PASSWORD on the server…"You are opening the page from another machine. Ask the administrator to set access codes
Admin or dashboard says "database not reachable"The database is down or restarting. The page retries by itself; tell the administrator if it lasts
Every line shows Scenario 1Normal at the start: there is no history yet. Streaks build up one check per day
No automatic runs happenedCheck Admin → Settings: is Run automatically on? The Health card on Overview shows the scheduler heartbeat
A vendor got no messageIs the vendor ticked under Vendors to follow up? Is pilot mode on? Check the vendor's numbers
WhatsApp shows FAILED or INVALID_MOBILEFix the vendor's number in Edit on the dashboard
The phone does not ringThe number must include country code, e.g. +91… Ask the administrator to check the FreJun setup
The call connects, then dropsThe server may be asleep. Open the site once to wake it, then call again
The agent is silentAsk the administrator to check the Gemini key and the server logs

Will vendors get the same message twice? No. Each vendor gets at most one message per scenario per day, even if a run is started twice.

What if the server was off for a day? That day neither counts nor breaks the streak. Escalation continues from where it was.

Can I try things without messaging real vendors? Yes. Use the Test environment, or keep pilot mode on: every message goes to the pilot number.
